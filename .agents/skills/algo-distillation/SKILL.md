# Algorithm Distillation skill

The deliverable of this harness is **a simple and elegant algorithm that
cracks the puzzle for the best achievable score**.  Distillation is the step
that turns a working-but-messy solver into that artifact.

## When to distil

After a run where: solve rate is 100% (or honest and reported), the score is
recorded, and the solver is deterministic and budgeted.

## What the artifact contains

`puzzle_cracker/strategy.py` (generated by the harness, then curated):

1. The **one idea per phase** explanation (e.g. "phase = a BFS parent-tree
   over a small reduced coordinate; four phases, four dictionary lookups");
2. the measured scorecard (solve rate, total moves, mean length, command,
   date, machine);
3. the plain-Python reference invocation.

## Distillation checklist

- [ ] Every solver claim verified: scramble -> solve -> check solved;
- [ ] Budgets explicit; no solver can hang;
- [ ] Score recorded in `docs/scorecards/`;
- [ ] The algorithm fits in one screen of prose + one code block;
- [ ] The move names match the competition's generator set;
- [ ] No credentials in the artifact.

## Anti-patterns

- shipping an unmeasured "improvement";
- replacing a working 60-line solver with a 600-line one "just in case";
- claiming optimality without an oracle on small scrambles;
- leaving dead code paths in the distilled artifact.
